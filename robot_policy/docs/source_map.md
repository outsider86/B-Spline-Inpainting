## Audited gaps and corrections

- `dd-openvla` contains no prior-plan discrete RTC training path despite the task's initial expectation; this project combines its protected corruption/block rules with deployment-available previous-policy predictions.
- StarVLA's current expected auxiliary L1 is argmax-decoded MAE and is nondifferentiable; it is not reused.
- StarVLA's stochastic selection ordering can remask the highest-confidence item; target code deterministically retains confidence and remasks the lowest.
- StarVLA's FM time transform can be slightly negative for about 0.15% of draws; target code clamps it.
- Neither reference provides the required timestamped modular asynchronous executor.
- The restrictive reference launch tree contains an embedded external-service credential. It is neither reproduced nor consumed; repository owners should revoke and remove it.
